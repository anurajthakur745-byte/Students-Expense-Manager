# Project Statement

## Problem Statement
Students often record daily expenses informally, making it difficult to understand spending patterns and remain within a monthly budget. This project provides a simple Python-based expense management system for recording, storing, deleting, and analysing student expenses.

## Scope
The project covers local expense entry, validation, CSV storage, category-wise reporting, total spending and basic budget-status analysis. It is a command-line application and does not include online accounts or cloud synchronization.

## Target Users
- College and university students
- Users who want a simple personal expense tracker

## High-Level Features
1. Add and validate expenses.
2. View and delete stored expenses.
3. Generate category-wise summaries.
4. Check spending against a user-defined budget.
5. Persist data in a CSV file.
